# Meta CRM

Free CRM for Meta Ads work: leads, follow-ups, clients, campaigns and budgets.

- Google login (Firebase Auth, project driver-saathi-241e6, Spark free plan)
- Data saves in Firestore under `users/{uid}/crm_leads` and `users/{uid}/crm_clients`
- Only the signed-in user can read or write their own data
- No monthly fee, no billing

Live: https://jerryagarhari2014.github.io/meta-crm/
